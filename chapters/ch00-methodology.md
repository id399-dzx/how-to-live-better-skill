# 第 0 节 前言 · 各节简介 · 本书方法论

## Core Idea
这是一份按性价比排好的备选单，不是任务清单。全书 667 条建议围绕四样东西展开——寿命、时间与精力、金钱、人身自由——每条都写明「花掉什么、换回什么、证据有多硬」。挑走一两条就算数，作者自己也没做到其中大部分。

## 怎么用这本书
- **不用全做。** 挑走一两条就算数，剩下的放着，需要时再回来查。「说着容易做着难」这个评价是对的，写下来是为了要用的时候找得到。
- **按节内顺序读。** 每节内条目按性价比从高到低排列，从每节前几条开始看就行。
- **只看「说人话」那一行就够拿主意。** 它把「收益」栏里的研究写法翻成「同期死亡的概率低约两成」「拘留几日、罚多少钱」这样的日常说法，只用收益栏已写到的内容，不添新数字。想自己核对就看「收益」栏，那里原样留着全部数字。
- **想挑最省力的：** 性价比「极高」共 114 条（17%）——既不花钱、不花时间、不需要毅力，收益又落在最大一档。
- **想挑结论最硬的：** 证据等级 A 共 435 条——有具体数字、来自荟萃分析或大型试验。
- **「不要」开头的节标题不用紧张。** 节标题说的是这一节想防住的事（不要早死、不要浪费时间），不是说底下每条都在让你别干什么。真正要做的动作写在条目标题里，一律动词开头。同一节里两种都有：第 4 节既有「把『打算做』写成『几点、在哪、遇到什么就做什么』」，也有「不看电视和滚动新闻」。按条目标题读。
- **条目之间会互相指路**（「见第 8 节第 17 条」这种）。不翻过去也知道说的是哪条，因为每处指路后面都写着指向什么。

## 关键概念
- **四种资源**：本书想帮你多留住的——寿命、时间与精力、金钱、人身自由。「不因为不知道一条红线，把自己送进拘留所或者看守所」是第四样的原话。
- **证据等级 A / B / C**：A = 有具体数字可查，出处是荟萃分析、大型队列或 RCT，能说出降了多少；B = 有研究支持但说不出确切数字，或只有小样本/单项研究；C = 作者经验或公认做法，无直接文献。全书 A 级 435 条、B 级 177 条、C 级 55 条，另有 68 条标「争议」、3 处标「待核实」。
- **性价比 极高 / 高 / 一般**：好处大、三项成本（钱/时间精力/毅力）又全是零 = 极高；好处大、成本不高，或好处中等、成本为零 = 高；其余 = 一般。全书极高 114 条（17%）、高 303 条（45%）、一般 250 条（38%）。
- **收益量级 大 / 中 / 小**：换寿命看降了百分之几（≥20% 为大，10–20% 为中，<10% 或只量到中间指标为小）；换钱看金额（万元级为大，数百到数千为中，几十元为小）；换人身自由看后果（避免刑事责任为大，避免拘留或行政处罚为中，避免民事纠纷为小）；换时间精力看省下多少（每天小时级为大，每周小时级为中，只省一次为小）。
- **受益对象四档**：① 你自己；② 配偶和直系亲属；③ 朋友、同事和其他亲属；④ 陌生人。不同档不合并计算；写到第 ④ 档时好处和风险一起写。
- **各算各的，不互相折算**：死亡率的数字、时间精力的数字、金钱的数字和法律后果，彼此之间不比大小。「总死亡率降 12%」和「每年省 500 元」不在一把尺子上。

## 心智模型
- **「证据硬」和「值得做」是两回事。** 证据等级只回答「这个数字可不可信」，性价比档才回答「这件事值不值得做」。一条可以证据是 A 级、性价比却只算一般（带状疱疹疫苗有 97.2% 效力的三期 RCT，但两针三四千元、带状疱疹很少致命）；也可以证据只有 C 级、性价比却极高（出境前把行程发给家人）。性价比档是作者自己的判断，按本书标准它本身只算 C 级。
- **A 级不等于因果。** A 级里既有随机分组的试验，也有只跟踪记录、不分组的研究，后者分不清是这件事起了作用，还是做这件事的人本来就更健康。看收益栏：写着「随机分成两组」的是前者，写着「只记录、不分组」的是后者。
- **百分比是「低几成」，不是「每一百人少几个」。** 同样低 12%，本来风险就高的老人少掉的死亡人数，远多于本来风险就很低的年轻人。先看说人话里写的是哪些人，再看那个百分比。
- **把急救那节按受益对象四档读。** 中国 38,227 例院外心脏骤停里 79.2% 发生在家里，学按压首先是为了按在自家人身上；「看到有人溺水自己不下水」「撞见斗殴别上手拉架」这类规则本身就是自保规则，防的是你从旁观者变成第二个伤者。
- **「一般」不等于不该做。** 全书条目都是建议做的，只是这一档得你自己掂量那笔花销值不值。

## 反模式
- **把这本书当任务清单，试图全部做完。** 作者明说「作者自己也没做到其中大部分」。
- **拿成本栏的数字去引用。** 成本那一栏是作者按市面价格的粗略估计，只用来互相比较。
- **只挑贵的做。** 排在最前面的几乎都不花钱、也不需要毅力，昂贵的动作反而往后排（安全带、烟感报警器在前，几千元的筛查在后）。
- **把 A 级当成「一定是这件事起了作用」。** 见上条心智模型。
- **跨口径比大小。** 「降 12% 死亡率」和「每年省 500 元」无法分高下，本书刻意不做这种折算。

## Worked Example
假设问题是「家里老人 70 岁，客厅到卫生间要过一个门槛，要不要装扶手、做防跌倒改造」。按本书的方式走一遍：

1. **定位节。** 四样资源里这是「换寿命」，对应第 1 节（不要早死）第 13 条「60 岁以上练平衡和腿部力量，改造家里的浴室和楼梯」。
2. **看成本。** 每周 2 到 3 次太极或平衡训练 + 家里改造；不花钱到几百元。
3. **看说人话和收益。** 跌倒次数降 23%（RaR 0.77），太极再降约 29%（RR 0.71）。中国老人跌倒有 55.97% 发生在家中——这一条的前提「发生在家中」正好成立。
4. **看证据等级。** A 级。但要确认收益栏写的是「随机分成两组」还是「只记录、不分组」，前者才能说「是练了才少摔」。
5. **看备注边界。** 有没有写「只针对某类人群」「某类人不适用」。
6. **看性价比档。** 成本低、收益量级中等偏上 → 落在「高」或「极高」，属于值得先做的。
7. **决定。** 做，但只做这一条，不连带把整节 42 条都做掉。

## 关键要点
1. 这是备选单不是任务清单，挑一两条就够。
2. 每节内按性价比从高到低排，从前几条开始看。
3. 「说人话」一行够拿主意，「收益」栏留着全部数字供核对。
4. 证据等级管「数字可不可信」，性价比档管「值不值得做」，两者互不影响。
5. 四种资源各算各的：寿命、时间精力、金钱、人身自由，不互相折算。
6. A 级不等于因果——看收益栏写的是「随机分组」还是「只记录」。
7. 百分比是「低几成」，先看适用人群再看数字。
8. 只想看最值得做的：性价比「极高」114 条；只想看结论最硬的：证据等级 A 的 435 条。
